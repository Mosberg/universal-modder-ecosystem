Core setup

Install the required foundation first. uv is recommended because it installs the um CLI and its Python dependencies in an isolated environment.

Windows PowerShell — prerequisites 
winget install --id Git.Git -e --source winget
winget install --id Python.Python.3.12 -e --source winget
winget install --id Gyan.FFmpeg -e --source winget
winget install --id astral-sh.uv -e --source winget
Install Universal Modder Unrestricted 
git clone https://github.com/AhmedTahaAtiya/universal-modder-unrestricted.git
cd universal-modder-unrestricted
uv tool install --force git+https://github.com/AhmedTahaAtiya/universal-modder-unrestricted
um --help
Required: Git, Python 3.10+, FFmpeg.
Recommended: uv.
Optional: Blender for 3D-to-sprite rendering, fal for hosted generative assets, and ComfyUI for local image generation.

Recommended workflow

  1. Scan the game: use um scan to identify likely engine, formats, executable, and modding route.
  2. Check prior work: run um kb search "<game or engine>" before reverse engineering.
  3. Inspect and modify: use Ghidra, x64dbg, Cheat Engine, HxD, Resource Hacker, or engine-specific tools as appropriate.
  4. Generate assets: use fal MCP for hosted generation or ComfyUI for local images.
  5. Prepare art: use Aseprite, Krita, GIMP, TexturePacker, or Blender depending on the asset type.
  6. Test in game: use the game itself, OBS for capture, and um win for Windows automation.
  7. Document results: let the agent write a knowledge-base field note with versions, route, verification, and gotchas.

Built for the Universal Modder ecosystem. Always mod only games you legally own and respect each game’s terms of service, licenses, and platform rules.
